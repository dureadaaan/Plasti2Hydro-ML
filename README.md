# 🧪 Plasti2Hydro-ML

**Predicting Hydrogen Production from Plastic Waste using Machine Learning**

---

### 📖 **Overview**

**Plasti2Hydro-ML** is a research-driven machine learning project focused on predicting **hydrogen (NH₃) production** from **plastic waste conversion** processes.
The project explores how process parameters — such as **PE/PP ratio**, **steam-to-plastic ratio**, **temperature**, **natural gas-to-plastic ratio**, and **pressure** — influence the hydrogen output rate.

The goal is to apply and compare multiple ML models while understanding their backend behavior through **feature engineering**, **model fitting**, **feature importance**, and **error analysis**.

---

### ⚙️ **Key Steps Implemented**

* **Data Preprocessing:** Handling missing values, normalization, and feature scaling
* **Feature Engineering:** Transforming input features for better model performance
* **Model Training:** Applying Linear Regression, Random Forest, and other ML algorithms
* **Evaluation Metrics:** Training/Test accuracy, loss, and performance comparison
* **Visualization:**

  * Correlation heatmap
  * Feature importance bar charts
  * Predicted vs Actual plots
  * Training & validation loss curves

---

### 🧩 **Dataset**

Dataset: *Hydrogen Production from Plastic Waste*
Features include:
`PE/PP`, `Steam/Plastic`, `Tg (°C)`, `NG/Plastics`, `P-NH3 (bar)`
Target variable: `NH3 (kg/h)`

---

### 🧠 **Objective**

To identify the most influential parameters in hydrogen generation and develop a reliable predictive model for optimizing plastic-to-hydrogen conversion efficiency.
